## Частина A. Збір експериментальних даних

### Завдання A.1. Формування запиту вручну

**Команда:**

```

```

```

Connection: close
```

```
set-cookie: served=1:TCP:IPv4

```

## Частина B. Розбір полів заголовка

Розбирається відповідь, отримана в завданні A.1.

**Загальна кількість полів заголовка у відповіді:**

| № | Поле заголовка | Значення | Призначення (власне формулювання) | Походження: сервер / проміжний вузол / не визначено | Обґрунтування |
|---|---|---|---|---|---|
| 1 | content-length | 0 | повідомляє розмір тіла відповіді | не визначено | розмір тіла в 0 байт показує те що передалися тільки службові заголовки |
| 2 | location | [http://www.haproxy.org/](http://www.haproxy.org/) | повідомляє про нову адресу на яку клієнт повинен перейти| сервер | якщо браузер отримує цей заголовок зі статусом 301 він автоматично перенаправляє користувача на цю адресу |
| 3 | alt-svc | h2=":443"; ma=3600 | повідомляє клієнту про підтримку новішої версії протоколу | проміжний вузол | сервер підтримує HTTP/2 через порт 443 (HTTPS), також вказано щоб клієнт зберігав цю інформацію в кеші протягом 3600 секунд |
| 4 | alt-svc | h3=":443"; ma=3600 | повідомляє клієнту про підтримку новішої версії протоколу | проміжний вузол | теж саме що і в полі під номерм 3 але про HTTP/3 |
| 5 | set-cookie | served=1:TCP:IPv4 | повідомляє про встановлення cookie | проміжний вузол | діагностичний маркер балансувальника який фіксує, який сервер обробив запит та параметри мережі |
| 6 | connection | close | керування з'єднанням | проміжний вузол | TCP-з'єднання було закрито одразу після відправки цієї відповіді |

> Рядок наводять на кожне поле, яке реально надійшло. Зайві рядки вилучають, за потреби додають нові. Поле, походження якого встановити не вдалося, зазначають із позначкою «не визначено» та поясненням утруднення.
